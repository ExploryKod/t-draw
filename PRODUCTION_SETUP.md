# Production Setup Guide - t-draw (Docker)

This guide will help you deploy t-draw to production using Docker.

## 📋 Prerequisites

- VPS with Ubuntu 20.04+ (or similar Linux distribution)
- Docker installed
- Docker Compose installed (or Docker with compose plugin)
- Domain name pointing to your VPS IP
- SSH access to your VPS

## 🚀 Quick Start

### 1. On Your VPS

```bash
# Clone your repository
cd /opt
sudo git clone YOUR_REPO_URL t-draw
cd t-draw

# Create production environment file
cp .env.production.example .env.production
nano .env.production  # Configure with your production values
```

### 2. Configure .env.production

**Required variables to update:**

```env
APP_NAME=Colladraw
APP_ENV=production
APP_KEY=                    # Will be auto-generated by deploy script
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=mysql
DB_HOST=mysql               # Container name, don't change
DB_PORT=3306
DB_DATABASE=colladraw_prod
DB_USERNAME=colladraw_user
DB_PASSWORD=your_secure_password_here
DB_ROOT_PASSWORD=your_root_password_here

# WebSocket Configuration
WS_PORT=8001
WEBSOCKET_URL=https://yourdomain.com
ALLOWED_ORIGINS=https://yourdomain.com
```

**Important:**
- `APP_KEY` will be auto-generated if empty
- `DB_HOST` must be `mysql` (the container name)
- `WEBSOCKET_URL` should match your `APP_URL` (same domain)
- Use strong passwords for database credentials

### 3. Set Up SSL Certificates

**Option A: Let's Encrypt (Recommended)**

```bash
# Install certbot
sudo apt install certbot

# Get certificate (replace with your domain)
sudo certbot certonly --standalone -d yourdomain.com -d www.yourdomain.com

# Copy certificates to Docker directory
sudo mkdir -p docker/nginx/ssl
sudo cp /etc/letsencrypt/live/yourdomain.com/fullchain.pem docker/nginx/ssl/cert.pem
sudo cp /etc/letsencrypt/live/yourdomain.com/privkey.pem docker/nginx/ssl/key.pem
sudo chmod 644 docker/nginx/ssl/cert.pem
sudo chmod 600 docker/nginx/ssl/key.pem
```

**Option B: Self-signed (Development/Testing Only)**

```bash
mkdir -p docker/nginx/ssl
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout docker/nginx/ssl/key.pem \
  -out docker/nginx/ssl/cert.pem \
  -subj "/C=US/ST=State/L=City/O=Organization/CN=yourdomain.com"
```

### 4. Update Nginx Configuration

Edit `docker/nginx/conf.d/app.conf` and replace `server_name _;` with your domain:

```nginx
server_name yourdomain.com www.yourdomain.com;
```

### 5. Deploy

```bash
# Make deploy script executable
chmod +x deploy-prod.sh

# Run deployment
./deploy-prod.sh
```

The script will:
- ✅ Check prerequisites
- ✅ Generate APP_KEY if needed
- ✅ Build Docker images
- ✅ Start containers
- ✅ Run database migrations
- ✅ Optimize Laravel caches
- ✅ Set proper permissions

### 6. Verify Deployment

```bash
# Check container status
docker compose -f docker-compose.prod.yml ps

# Check logs
docker compose -f docker-compose.prod.yml logs -f

# Test WebSocket connection
curl -I https://yourdomain.com/socket.io/
```

## 🔄 Updates

To update your application:

```bash
cd /opt/t-draw

# Pull latest code
git pull origin main

# Rebuild and restart
docker compose -f docker-compose.prod.yml build
docker compose -f docker-compose.prod.yml up -d

# Run migrations if needed
docker compose -f docker-compose.prod.yml exec app php artisan migrate --force

# Clear caches
docker compose -f docker-compose.prod.yml exec app php artisan config:cache
docker compose -f docker-compose.prod.yml exec app php artisan route:cache
docker compose -f docker-compose.prod.yml exec app php artisan view:cache
```

## 📊 Monitoring

```bash
# View all logs
docker compose -f docker-compose.prod.yml logs -f

# View specific service logs
docker compose -f docker-compose.prod.yml logs -f app
docker compose -f docker-compose.prod.yml logs -f websocket
docker compose -f docker-compose.prod.yml logs -f nginx
docker compose -f docker-compose.prod.yml logs -f mysql

# Check container status
docker compose -f docker-compose.prod.yml ps

# Check resource usage
docker stats
```

## 🗄️ Database Management

```bash
# Backup database
docker compose -f docker-compose.prod.yml exec mysql mysqldump -u root -p${DB_ROOT_PASSWORD} ${DB_DATABASE} > backup_$(date +%Y%m%d).sql

# Restore database
docker compose -f docker-compose.prod.yml exec -T mysql mysql -u root -p${DB_ROOT_PASSWORD} ${DB_DATABASE} < backup.sql

# Access MySQL CLI
docker compose -f docker-compose.prod.yml exec mysql mysql -u root -p${DB_ROOT_PASSWORD}
```

## 🔒 Security Checklist

- [ ] `APP_DEBUG=false` in `.env.production`
- [ ] Strong database passwords set
- [ ] SSL certificate installed and valid
- [ ] Firewall configured (UFW) - only ports 80, 443 open
- [ ] `.env.production` file permissions: `chmod 600 .env.production`
- [ ] Regular database backups scheduled
- [ ] Containers set to `restart: unless-stopped`

## 🆘 Troubleshooting

### WebSocket not connecting

1. Check WebSocket container is running:
   ```bash
   docker compose -f docker-compose.prod.yml ps websocket
   ```

2. Check WebSocket logs:
   ```bash
   docker compose -f docker-compose.prod.yml logs websocket
   ```

3. Verify `ALLOWED_ORIGINS` in `.env.production` includes your domain

4. Check Nginx proxy config for `/socket.io/` path

### 502 Bad Gateway

1. Check if app container is running:
   ```bash
   docker compose -f docker-compose.prod.yml ps app
   ```

2. Check PHP-FPM logs:
   ```bash
   docker compose -f docker-compose.prod.yml logs app
   ```

3. Verify database connection:
   ```bash
   docker compose -f docker-compose.prod.yml exec app php artisan migrate:status
   ```

### Database connection errors

1. Verify database credentials in `.env.production`
2. Check MySQL container:
   ```bash
   docker compose -f docker-compose.prod.yml ps mysql
   docker compose -f docker-compose.prod.yml logs mysql
   ```

3. Test connection:
   ```bash
   docker compose -f docker-compose.prod.yml exec app php artisan migrate:status
   ```

### SSL Certificate Issues

1. Verify certificates exist:
   ```bash
   ls -la docker/nginx/ssl/
   ```

2. Check certificate permissions:
   ```bash
   chmod 644 docker/nginx/ssl/cert.pem
   chmod 600 docker/nginx/ssl/key.pem
   ```

3. Check Nginx logs:
   ```bash
   docker compose -f docker-compose.prod.yml logs nginx
   ```

## 📝 Useful Commands

```bash
# Stop all containers
docker compose -f docker-compose.prod.yml down

# Stop and remove volumes (⚠️ deletes database)
docker compose -f docker-compose.prod.yml down -v

# Restart specific service
docker compose -f docker-compose.prod.yml restart app
docker compose -f docker-compose.prod.yml restart websocket

# Execute commands in container
docker compose -f docker-compose.prod.yml exec app php artisan [command]
docker compose -f docker-compose.prod.yml exec app bash

# View real-time logs
docker compose -f docker-compose.prod.yml logs -f --tail=100
```

## 🎯 Architecture

```
Internet
    ↓
Nginx (Port 80/443)
    ↓
├──→ PHP-FPM (Laravel App) - Port 9000
├──→ WebSocket Server - Port 8001
└──→ MySQL - Port 3306 (internal only)
```

All services run in Docker containers with automatic restart on failure.
